FROM BROWSER TO DATABASE

How It Came Together

From a customer’s browser to MongoDB: a look at how EcoCraft comes together.

01 · THE EXPERIENCE

HTML, CSS & JavaScript

The Flask-served interface handles browsing and sends requests to the application API.

02 · THE APPLICATION

Python & Flask

Flask handles API requests, validation and role-based permissions; PyMongo connects the application to the database.

03 · THE DATA

MongoDB Atlas

MongoDB stores the marketplace data used throughout the application.
