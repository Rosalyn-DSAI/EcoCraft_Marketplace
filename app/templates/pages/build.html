THREE LAYERS, WORKING TOGETHER

Each layer has a part to play.

01

THE EXPERIENCE

HTML, CSS & JavaScript

The Flask-served frontend brings product discovery, shopping, artist tools and administration into an interactive browser experience.

02

THE APPLICATION

Python, Flask & PyMongo

Flask receives API requests, applies validation and permissions, and coordinates the marketplace's business rules. PyMongo connects the application to MongoDB.

03

THE DATA

MongoDB Atlas

The cloud-hosted NoSQL database stores the users, products, carts, orders and reviews that support marketplace workflows.

A REQUEST, AND ITS WAY BACK

Working together as one system.

A browser request travels through Flask and PyMongo to MongoDB Atlas. The resulting information returns through the same application path.
